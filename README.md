## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lovewanshik2000/Kamlesh-Lovewanshi-Portfolio.git
   cd Kamlesh-Lovewanshi-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local dev server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🚀 Deployment

This project includes a pre-configured GitHub Actions workflow (`.github/workflows/deploy.yml`).
When pushed to the `main` branch, GitHub Actions will automatically install dependencies, build the project, and deploy it to **GitHub Pages**.

To enable GitHub Pages:
1. Go to your repository settings on GitHub (`Settings` > `Pages`).
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. Push to `main` and your portfolio will be deployed live!
